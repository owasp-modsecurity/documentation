The rule language and configuration reference for ModSecurity v2 and libModSecurity v3.

Each directive, variable, transformation, action and operator is documented once. The metadata table under each entry
shows the ModSecurity v2 version it first appeared in, and whether libModSecurity v3 supports it.

Badge legend:

| Badge | Meaning |
|:--|:--|
| <span class="badge cstyle green"><span class="badge-content">since 2.7.0</span></span> | available from that release on |
| <span class="badge cstyle green"><span class="badge-content">supported</span></span> | available, first release not recorded |
| <span class="badge cstyle orange"><span class="badge-content">not implemented yet</span></span> | accepted by the parser or planned, but not functional in libModSecurity v3 |
| <span class="badge cstyle red"><span class="badge-content">not supported</span></span> | not available in that engine |
| <span class="badge cstyle grey"><span class="badge-content">unknown</span></span> | not verified yet |
